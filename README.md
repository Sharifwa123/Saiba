# SAIBA Android app — APK downloads

**SAIBA** is a WhatsApp-first AI business assistant by **SHARIF AI**: it
answers customers on WhatsApp (and other channels) using your own
business knowledge, and hands the conversation to a person only when it
actually needs one. This repo holds nothing else but signed Android APK
releases for the SAIBA mobile app — no source code here. The app itself
is built from [Sharifwa123/SHARIF-AI](https://github.com/Sharifwa123/SHARIF-AI)
(private) and every successful build is published here automatically.

Website: **[saiba.shariftechnologies.online](https://saiba.shariftechnologies.online/)**

This repo exists because SAIBA isn't on the Google Play Store yet. Once
it is, downloads here will stop and this repo can be archived or
removed — until then, this is the place to get the Android app.

## Download SAIBA for Android

Go to **[Releases](../../releases/latest)** and download the `.apk` file
under the newest release. Android will likely ask you to allow "install
from unknown sources" the first time — that's expected for an app
installed outside the Play Store.

The app itself checks this repo's latest release on launch and will show
an in-app banner with a direct link here if a newer build is available,
so you don't need to check back manually.

## What SAIBA does

- Answers customer questions on WhatsApp from your business's own
  documents, policies and FAQs
- Connects other channels (Instagram, Facebook, email, web chat) to the
  same assistant
- Escalates a conversation to a real person the moment it needs one
- Runs from one workspace: assistants, knowledge, conversations and
  orders in one place
