# SAIBA — Android downloads

This repo holds nothing but signed Android APK releases for **SAIBA by
SHARIF AI**, a WhatsApp-first business assistant. There is no source code
here — the app itself is built from [Sharifwa123/SHARIF-AI](https://github.com/Sharifwa123/SHARIF-AI)
(private) and every successful build is published here automatically.

This repo exists because SAIBA isn't on the Google Play Store yet. Once it
is, downloads here will stop and this repo can be archived or removed —
until then, this is the place to get the app.

## Download

Go to **[Releases](../../releases/latest)** and download the `.apk` file
under the newest release. Android will likely ask you to allow "install
from unknown sources" the first time — that's expected for an app
installed outside the Play Store.

The app itself checks this repo's latest release on launch and will show
an in-app banner with a direct link here if a newer build is available,
so you don't need to check back manually.
